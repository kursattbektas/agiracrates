# agiracrates
🐉 **AgiraCrates** is an advanced Minecraft crate plugin featuring ItemsAdder 3D models, 5 unique animations, custom holograms, rarity-based rewards, secure physical and virtual keys, Pity system, GUI editor, reward history, and English/Turkish support.  **Paper | Minecraft 1.16.5+ | Tested on 1.21.11**
